# OutbreakLens final mark

Concept 02, Herd in the lens. Navy #1F3864, terracotta #C0532B, paper #FAF7F1. The wordmark is Open Sans Regular, outlined. No SVG uses masks or IDs. Files marked "on-navy" are paper and terracotta on a transparent background.

## SVG masters

- mark.svg: navy mark for light backgrounds
- mark-on-navy.svg: mark for dark backgrounds
- mark-mono-navy.svg, mark-mono-paper.svg: one-colour marks
- mark-small.svg: ring, dot and hen for 24 px use
- lockup-horizontal.svg, lockup-stacked.svg and their -on-navy versions: logo with wordmark
- endcard-mark.svg: 300 px mark for the shorts end card
- header-inline.svg: website header mark. It replaces `_mark("brand-mark")` in build_site.py, and the `.brand-mark` CSS sizes it to 28 px

- favicon.svg, favicon.ico, favicon-16.png, favicon-32.png, favicon-48.png: browser icons. favicon-16 is ring and dot only
